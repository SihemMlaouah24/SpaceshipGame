# 🚀 2.5D Spaceship Shooter Game

This is a personal 2.5D desktop spaceship shooter game developed in Unity as part of my self-learning journey in game development. The player controls a spaceship navigating through levels, avoiding and shooting obstacles while exploring core gameplay mechanics.

## 🎮 Project Overview

- **Type:** Personal Project  
- **Platform:** Desktop (Windows/macOS)  
- **Perspective:** 2.5D  
- **Engine:** Unity (2019)  
- **Language:** C#  
- **Purpose:** Learning project to explore Unity fundamentals such as movement, shooting mechanics, physics, and collision detection.

## 🛠️ Features

- Spaceship movement and controls  
- Obstacle generation and destruction  
- Shooting system with projectile mechanics  
- Collision detection and response  
- Level design with progressive difficulty

## 🧪 Technologies Used

- **Unity (2019)** – Game engine used for development  
- **C#** – Scripting language for game mechanics and interactions
